# SessionEdge

[English](README.md) · [Deutsch](README.de.md) · [Español](README.es.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Português](README.pt.md) · **Русский** · [日本語](README.ja.md) · [简体中文](README.zh_CN.md)

Плагин для [DankMaterialShell](https://github.com/AvengeMedia/DankMaterialShell), который держит действия сеанса на узкой панели у края экрана. Подведите указатель к краю, и панель выедет из рамки. Уведите его, и панель уедет обратно.

![SessionEdge](assets/screenshot.png)

Пошагово с картинками: [руководство по установке и настройке](docs/GUIDE.ru.md).

## Что он делает

На панели есть «Заблокировать», «Ждущий режим», «Гибернация», «Выйти», «Перезагрузить», «Выключить» и «Перезапустить оболочку». Каждую кнопку можно скрыть в настройках.

Это обычное всплывающее окно DMS. Если рамка DMS работает в сплошном режиме, панель выходит из рамки и использует её контур и фон. Без рамки она открывается как обычное всплывающее окно.

Панель можно разместить у любого края или на стороне панели DMS и выровнять по началу, центру или концу этого края. На указатель реагирует только короткий участок края, и перед открытием есть небольшая задержка, поэтому панель остаётся закрытой, когда указатель просто проходит мимо.

Для «Ждущий режим», «Гибернация», «Выйти», «Перезагрузить» и «Выключить» нужно нажать и удерживать кнопку, время удержания такое же, как в меню питания DMS. «Заблокировать» и «Перезапустить оболочку» срабатывают по щелчку. Все действия идут через службы сеанса DMS, так же как в меню питания.

## Требования

DankMaterialShell 1.6.1 или новее. Должно работать на всех композиторах, которые поддерживает DMS. Я пользуюсь им в niri.

## Установка

```sh
git clone https://github.com/satoshoe-dev/dms-sessionedge ~/.config/DankMaterialShell/plugins/SessionEdge
dms ipc call plugins enable sessionEdge
```

## Настройки

Настройки → Дополнения → SessionEdge

| Параметр | По умолчанию |
|---|---|
| Край | Справа |
| Положение на краю / Отступ от начала или конца | По центру / 0 px |
| Ширина полосы в покое | 8 px |
| Длина чувствительной зоны | 220 px |
| Размер кнопок | 52 px |
| Задержка открытия / Задержка закрытия | 180 / 500 мс |
| Видимые действия | все, кроме «Гибернация» |

## IPC

```sh
dms ipc call sessionEdge toggle
```

Команда открывает или закрывает панель, например по сочетанию клавиш в niri:

```kdl
Mod+Escape { spawn "dms" "ipc" "call" "sessionEdge" "toggle"; }
```

## Переводы

Страница настроек доступна на немецком, испанском, французском, итальянском, португальском, русском, японском и упрощённом китайском и следует языку, выбранному в DMS. Если перевод звучит неправильно, pull request приветствуется.
