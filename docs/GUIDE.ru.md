# SessionEdge: шаг за шагом

## 1. Установите плагин

Клонируйте репозиторий в папку плагинов DMS:

```sh
git clone https://github.com/21Rebel/dms-sessionedge ~/.config/DankMaterialShell/plugins/SessionEdge
```

## 2. Включите его

Откройте Настройки → Дополнения. SessionEdge появится в списке. Включите его.

![Список плагинов с SessionEdge](images/01-plugin-list.png)

Если его нет, нажмите «Сканировать» на этой странице или перезапустите оболочку командой `dms restart`.

## 3. Выберите край

Разверните SessionEdge в списке плагинов, чтобы увидеть его настройки. Выберите край, у которого будет полоса, и её положение на этом краю.

![Настройки SessionEdge](images/02-settings.png)

Если рамка DMS работает в подключённом режиме, полоса выезжает из рамки. Со стороны вашей панели область стыковки шире всего.

## 4. Откройте полосу

Подведите указатель к выбранному краю и задержите его там на мгновение. Полоса выедет.

![Полоса у правого края](images/03-strip.png)

Реагирует только короткий участок края (по умолчанию 220 px), поэтому полоса не открывается, когда указатель просто проходит мимо. Настройте «Длина чувствительной зоны» и «Задержка открытия», если она открывается слишком легко или слишком поздно.

## 5. Выполните действие

Блокировка и «Перезапустить оболочку» срабатывают по щелчку. Ждущий режим, гибернация, выход, перезагрузка и выключение требуют нажать и удерживать. Кнопка заполняется, пока вы её удерживаете.

![Удержание кнопки «Выйти»](images/04-hold.png)

Отпустите раньше, чтобы отменить.

## 6. Выберите кнопки

Внизу настроек отключите действия, которые вам не нужны. Гибернация появляется, только если система её поддерживает.

## 7. Открытие горячей клавишей (необязательно)

```sh
dms ipc call sessionEdge toggle
```

В niri добавьте в конфигурацию:

```kdl
binds {
    Mod+Escape { spawn "dms" "ipc" "call" "sessionEdge" "toggle"; }
}
```
